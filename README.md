## 📖 Description

**ELM Counter** is a simple yet interactive counter application built with the **Elm** functional programming language. This project demonstrates the core concepts of Elm including:

- **Model-View-Update (MVU)** architecture
- **Pure functions** and immutability
- **Type safety** and inference
- **Functional programming** principles
- **Elm's The Elm Architecture** (TEA)

---

## ✨ Features

- ➕ **Increment** - Increase the counter value
- ➖ **Decrement** - Decrease the counter value
- 🔄 **Reset** - Reset counter to zero
- 🎨 **Clean UI** - Minimal and responsive design
- ⚡ **Fast Performance** - Built with Elm's efficient runtime
- 📱 **Responsive** - Works on all screen sizes
- 🎯 **Type Safety** - Compile-time guarantees
